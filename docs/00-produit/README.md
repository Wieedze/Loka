## L'ordre des sources

En cas de contradiction, priorité décroissante :

1. les documents du client dans [`../06-sources/`](../06-sources/) ;
2. la **spec V1**, qui les traduit en comportement attendu ;
3. le cadrage client, antérieur à la réponse d'Oddwave.

## Ajouter une entrée

Un nouveau document produit prend le numéro suivant. Si le client répond aux
questions ouvertes, **ne pas réécrire l'historique** : mettre à jour
`03-questions-ouvertes.md`, et corriger la spec en indiquant la date et la
source de la réponse.
